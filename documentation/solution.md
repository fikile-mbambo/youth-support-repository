# Proposed Solution

## Overview

The Youth Support Directory will be a cloud-based information platform that helps young people locate verified organisations and services that provide youth support in South Africa.

The platform will organise support services into categories and allow users to search for relevant services based on their needs and location.

## Target Users

The primary users are young people in South Africa who are looking for information about available support services.

Secondary users may include:

- Parents or caregivers
- Teachers
- Social workers
- Community workers
- Youth organisations
- Other people assisting young people to access support

## Core Features

### 1. Service Search

Users will be able to search for support services.

### 2. Service Categories

Users will be able to browse services according to categories such as:

- Mental Health
- Counselling
- Gender-Based Violence Support
- Substance-Use Support
- Youth Development
- Social Services
- Crisis Support
- Sexual Health
- Disability Support
- Family Support

### 3. Location Filtering

Users will be able to filter services according to province and, where appropriate, city or area.

### 4. Organisation Information

Each directory listing will provide relevant information such as:

- Organisation name
- Service category
- Location
- Description of services
- Operating hours
- Telephone number
- Official website
- Other official contact methods

### 5. Verification Information

The project will record when service information was last verified.

This is intended to reduce the risk of presenting outdated contact information.

## Initial User Journey

A basic user journey will be:

1. User opens the Youth Support Directory.
2. User selects a support category.
3. User selects a location.
4. The system searches the directory.
5. Relevant organisations are displayed.
6. User selects an organisation.
7. The organisation's available information and official contact details are displayed.

## Privacy Approach

The initial version will not require users to create accounts or provide sensitive personal information.

The platform will focus on providing information about support services rather than collecting information about the user's personal circumstances.

## Project Scope

The initial project will focus on:

- Building a searchable service directory
- Storing service information
- Creating location and category filters
- Hosting the application using cloud infrastructure
- Applying security principles
- Monitoring the cloud environment
- Documenting the implementation

Future versions may introduce additional functionality.

## Expected Outcome

The expected outcome is a working prototype demonstrating how cloud computing can be applied to improve access to information about youth-support services.

The project will also demonstrate practical knowledge of AWS, Linux, Python, databases, networking, security, Terraform and Git/GitHub.
